01 / Overview & Architecture

This document details the exact information flow of Dynamic Edge Gesture Control. The application is designed to function with a strict local-first processing model. Core utilities—including touch interception, notch triggers, edge drawer rendering, shortcut execution, and private notes—process data exclusively within the volatile memory (RAM) and sandbox storage of your physical device.

Architecture Guarantee: The developer operates no independent account registry, tracking database, or synchronization server. The application functions completely offline for its core capabilities.

03 / Manifest Permissions Architecture

Every manifest entry corresponds directly to specific system actions available in your settings:

BIND_ACCESSIBILITY_SERVICE Strictly Isolated

The Accessibility Service is used solely to capture touch inputs (swipes, taps, pinches) within user-defined edge zones and to perform native system actions (e.g., Back, Home, Recents, Notifications shade, Split Screen, and Power Menu).

Prominent Privacy Disclosure: The service does not inspect on-screen text, monitor keypresses, record passwords, or intercept personal correspondence.

System Overlays & Foreground Execution
  • SYSTEM_ALERT_WINDOW: Renders tactile edge sliders, notch widgets, and pie menus over active apps without reading what is rendered beneath them.
  • FOREGROUND_SERVICE, FOREGROUND_SERVICE_SPECIAL_USE: Maintains persistent touch responsiveness across app launches without being purged by OS memory cleanup routines.
  • RECEIVE_BOOT_COMPLETED: Re-establishes configured triggers automatically following device restarts.
  • WAKE_LOCK, REQUEST_IGNORE_BATTERY_OPTIMIZATIONS: Ensures zero-latency wake response during rapid swipe gestures.
Hardware Control & Shortcuts
  • CAMERA, FOREGROUND_SERVICE_CAMERA: Dispatches hardware flashlight toggles and silent captures mapped to gestures.
  • RECORD_AUDIO, FOREGROUND_SERVICE_MICROPHONE: Records voice notes triggered on demand by assigned gestures.
  • FOREGROUND_SERVICE_MEDIA_PLAYBACK: Displays playback controls in notification areas for the local media widget.
  • WRITE_SETTINGS, MODIFY_AUDIO_SETTINGS, VIBRATE: Modifies brightness, stream levels, rotation locks, and haptic feedback.
  • BLUETOOTH_CONNECT, BLUETOOTH_SCAN: Toggles Bluetooth power state and connects paired devices from shortcut docks.
  • CALL_PHONE, READ_CONTACTS: Permits speed-dial shortcuts. Contact records are queried locally and strictly on-demand.
  • USE_BIOMETRIC, USE_FINGERPRINT: Authenticators run through Android's hardware security enclave to lock private notes.
  • com.m.payra.gesture.control.app.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION: An internal signature boundary ensuring system intents are handled strictly by the app's own process.

04 / Hardware Features & Optionality

The application declares multiple hardware capabilities using <uses-feature> in its manifest. These map directly to underlying hardware components:

• android.hardware.telephony (Direct Call Shortcut)
• android.hardware.camera / camera.autofocus (Flashlight / Quick Capture)
• android.hardware.microphone (Voice Memo Shortcut)
• android.hardware.bluetooth / bluetooth_le (Wireless Accessory Toggle)
• android.hardware.location / location.gps / location.network (Geofence Automation)
• android.hardware.faketouch (Broad Touchscreen & Pointer Compatibility)

Hardware Fallback: When a physical component is missing (such as telephony on a Wi-Fi-only tablet), that specific action is disabled gracefully while all other gestures remain operational.

05 / Package Visibility (QUERY_ALL_PACKAGES)

The app requests android.permission.QUERY_ALL_PACKAGES in compliance with Google Play's High-Risk Permission policy. This permission is necessary for two user-facing features:

  1. Application Shortcuts: Allows you to map any installed app to edge handles, pie wedges, and floating docks.
  2. Exclusion Profiles: Allows the service to detect foreground packages (e.g., active games or cameras) and automatically suppress edge touch triggers to avoid accidental touches.

Package inventory queries are computed entirely within local memory. Application lists are not compiled, sent over networks, or shared.

Network operations are restricted to Google LLC platform libraries:

Delivers optional rewarded and banner advertisements. AdMob uses the Google Advertising ID (AD_ID) and attribution tokens for conversion measurement under Google’s Advertising Terms.

Transmits anonymized crash logs, operating system versions, and exception stack traces over TLS to support software fixes under the Firebase Privacy Standard.

07 / Google Play Billing & Licensing

Pro upgrades are processed exclusively via the official Google Play Billing Library (com.android.vending.BILLING, CHECK_LICENSE).

Payment methods, card verification, and banking credentials are handled entirely by Google Play. The application receives and retains only cryptographic verification tokens confirming active license states.

08 / Data Retention & Deletion Rights

Local configurations, personal notes, and captured media stay on your device until manually deleted or until you clear data via Android Settings (Settings > Apps > Dynamic Edge Gesture Control > Storage > Clear Storage). Uninstalling the application purges its isolated storage directory.

Under GDPR and CCPA, you have the right to request deletion of any pseudonymous telemetry associated with your installation or advertising ID. Contact the address below to file an erasure request.
